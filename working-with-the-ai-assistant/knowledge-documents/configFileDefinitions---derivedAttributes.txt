2.9 derivedAttributes.jsonPurpose and ConsiderationsDerived attributes are attributes that are calculated based on information contained in other attributes – either based on raw attributes or other derived attributes. When a derived attribute is defined, high-level information needs to be described in this file – for example, attribute ID, label, data type, length, and the attributeType. There are many types of derived attributes – for each attributeType, information will ALSO need to be provided in an accompanying file. For attributes with attributeType=’code’, an associated record will exist in the ‘userDefinedCode.json’ file with SASAttributeID matching the SASAttributeID from the derivedAttributes json. For attributes of other attributeTypes, details related to the logic needed to compute the attribute should be contained in a record in the corresponding derivedAttributeDetails_<attributeType>.json file.Required fields* assetType (string) – contains the assetType for the derived attribute - must be a valid assetType in the assetTypes json file* attributeID (string) – contains the ID of the derived attribute. Must be unique per assetType. The assetType/attributeID cannot also exist in the attributes file as a raw attribute. This field should contain only letters, numbers, spaces, underscores, and dashes.* SASAttributeID (string) – contains the SAS attribute ID for the attribute – this is typically similar to the attribute ID but it has specific rules – it must be <=30 characters; contain only letters/numbers/underscores, and it cannot begin with a number* attributeLabel (string) – contains a display-friendly label for the attribute. Contains only letters, numbers, spaces, underscores, and dashes* attributeType (string) – describes the type of attribute - the only valid values are "lag", "delta", "temporalAgg", "relationalAgg", “countConn”, “getConn”, “getAssetID”, “getAssetLabel”, “getValue”, “code”, “searchEvents”* dataType (string) – describes the type of data that the attribute will hold - the only valid values are "double" and "string" – “double” is used for attributes that contain a numeric value and “string” is used for attributes that contain a text value* dataLength (number) – describes the length allowed for values of this attribute – should contain 8 if datatype=’double’ or a positive integer if datatype=’string’ (long enough to hold a typical value for that field)Optional fields* dataFormat – when values for this attribute are displayed to a user, they can be displayed using a valid format. If specified, this field needs to contain a valid SAS format* acceptableMin, acceptableMax – sets the min/max acceptable value for the attribute. If specified, the corresponding acceptableMinLogic/acceptableMaxLogic field needs to be set* acceptableMinLogic, acceptableMaxLogic – should be set IF an acceptable value was set. ‘limit’ means that values below the min or above the max are instead set to the min or max. ‘missing’ means that values below the min or above the max are ignored.Validation- Every derived attribute must have a matching entry in an associated file. For attributes with attributeType=’code’, an associated record MUST exist in the ‘userDefinedCode.json’ file with SASAttributeID matching the SASAttributeID from the derivedAttributes.json. For attributes of other attributeTypes, details related to the logic needed to compute the attribute should be contained in a record in the corresponding derivedAttributeDetails_<attributeType>.json file.Presentation rule:* When discussing a derived attribute with a user, only explain logic in natural language (e.g., “sum of all string currents within a combiner box”). DO NOT SHOW THE UNDERLYING JSON FILES UNLESS ASKED SPECIFICALLY.Example[  {    "assetType": "inverter",    "attributeID": "inv_current_sum",    "SASAttributeID": "inv_current_sum",    "attributeLabel": "Inverter Current Sum",    "attributeType": "relationalAgg",    "dataType": "double",    "dataLength": 8  },  {    "assetType": "string",    "attributeID": "current_A_5m_avg",    "SASAttributeID": "current_A_5m_avg",    "attributeLabel": "String Current 5m Avg",    "attributeType": "temporalAgg",    "dataType": "double",    "dataLength": 8  },{                "assetType": "solarFarm",                "attributeID": "testCode",                "SASAttributeID": "testCode",                "attributeLabel": "testCode",                "attributeType": "code",                "dataType": "double",                "dataLength": 8            }]--END OF FILE--
